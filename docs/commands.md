# Commands

Every command Suhina has, generated from the command registry in `crates/session` by
`suhina-cli commands --markdown`; do not edit by hand. A workflow regenerates it on `main`
after every merge, so pull requests leave it alone. The CLI, the MCP server and the UI run
these same commands ([ADR 0002](decisions/0002-commands.md), [`mcp.md`](mcp.md)).

| Command | Runs on, does | What it does | Parameters |
|---|---|---|---|
| `project.list` | projects read | List the open projects in tab order with id, name, source and whether each is active | none |
| `project.switch` | projects change | Make an open project the active one; the previous one stops playing | `project` (integer): project id, from project.list |
| `project.next` | projects change | Make the next open project active, wrapping around after the last | none |
| `project.previous` | projects change | Make the previous open project active, wrapping around before the first | none |

| `library.info` | library read | What an item is: a sample's length, rate, channels, tempo (and whether it was detected) and key; a MIDI file's tracks; a preset bank's voices; a device's or plug-in's role | `item` (library item): an item: a file's path, <bank>.syx#<voice>, device:<id> or plugin:<spec>, as library.search gives them |
