- 32-bit Windows plug-ins (VST2, VST3, CLAP) run in 64-bit Suhina through a 32-bit plug-in host
  installed beside the 64-bit one (`suhina-plugin-host-32.exe`): they are scanned, loaded,
  saved and shown with their editors like any other, each in its own sandboxed process. ARA is
  not available to 32-bit plug-ins.
