- **Instrument sample analysis** — the expanded Sample page can analyze an imported isolated
  note locally, propose its root key and show the residual tuning, or, for a loop or phrase,
  propose the tonic of its key (with a close alternative key shown) and the loop's tuning.
  Keys are shown as note names. Inspect or correct the key before accepting one undoable
  change; cancellation and stale results leave playback alone.
