- Swing (#1221): the project has a swing amount, set with the **Swing** slider beside **Resize all** in the Arrangement, that delays every second sixteenth of each eighth as MIDI clips play (up to the eighth-note triplet), live and in renders, the notes themselves unmoved. Every MIDI clip follows it until it gets its own in the clip panel's **Swing** row (the **Global** switch and a slider); turning **Global** back on keeps the clip's own amount for later. `transport.setSwing` and `clip.setSwing` do the same for agents; the project file is version 9.
