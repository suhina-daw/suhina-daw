# Specs

Clean-room specifications, written in our own words from observation, self-authored test files,
public documentation and open-source code under a GPL-compatible licence (see `CONTRIBUTING.md` ›
Clean-room). Code is implemented from these documents. Every spec names its sources: the program
and version it was observed with, the public documentation it follows, the test files it is based
on, and the open-source code it takes values or solutions from, with the file's path and the
commit.
